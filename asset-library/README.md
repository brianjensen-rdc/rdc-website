# Asset Library Archive

Full export of RDC's Squarespace media library, pulled ahead of the GitHub
Pages migration. 295 of 297 original files (268 images/GIFs, 27 videos).
Two orphaned draft videos were skipped -- both return a permanent 401 from
Squarespace itself (RDIdentity_Main_v4.mp4 and
RDIdentity_RoughPass_TM Score 2.0_v1.mp4), and both are superseded by
RDIdentity_Main_v6_LaunchDraft.mp4, which is included.

Videos were reconstructed at their highest available resolution (1080p
where offered) from Squarespace's encrypted HLS stream. Where two files in
the original library shared the same name, later duplicates were suffixed
__1, __2, etc.

This folder is a straight archive -- it is not wired into the Astro site
build and is not served by the live site.
